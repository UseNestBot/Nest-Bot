# Getting help

## Something isn't working

1. Make sure you're on the [latest release](https://github.com/UseNestBot/Nest-Bot/releases/latest).
2. Check the provider CLI works on its own. For example run `claude` or `codex` in a terminal and send a message. If that fails, it's a sign in or install problem with the CLI, not Nest.
3. In Nest, open **Settings** and hit **Recheck providers**.
4. Search [existing issues](https://github.com/UseNestBot/Nest-Bot/issues?q=is%3Aissue) in case someone already hit it.
5. Still stuck? [Open a bug report](https://github.com/UseNestBot/Nest-Bot/issues/new?template=bug_report.yml).

## Want something new

[Open a feature request](https://github.com/UseNestBot/Nest-Bot/issues/new?template=feature_request.yml).

## Security problems

Don't open an issue. Follow [SECURITY.md](SECURITY.md).

## Problems with a provider

Nest runs the official CLIs. Problems with your plan, rate limits, model access or the CLI itself belong with the provider:

- Claude Code: [anthropics/claude-code](https://github.com/anthropics/claude-code/issues)
- Codex: [openai/codex](https://github.com/openai/codex/issues)
- Gemini CLI: [google-gemini/gemini-cli](https://github.com/google-gemini/gemini-cli/issues)
